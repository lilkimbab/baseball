# 01. 참고작 조사 — 프로야구2K / 프로야구2K14

조사일 2026-11-20. 당시 기사·가이드·위키를 읽어 확인한 내용만 적었다. 확인하지 못한 것은 [7. 확인하지 못한 것](#7-확인하지-못한-것)에 따로 모았다.

이 문서는 참고작이 **어떤 게임이었는지**를 기록한다. 우리 게임의 설계는 [02](02-game-design.md) 이후 문서에 있다. 무엇을 가져오고 무엇을 새로 만드는지는 [README](../README.md#무엇을-만들고-무엇을-만들지-않는가)에, 참고작의 시행착오에서 얻은 교훈은 [6. 평가와 교훈](#6-평가와-교훈)에 정리했다.

## 2. 게임 구조

핵심 구상은 **매니지먼트(시뮬레이션) 위에 액션 개입을 얹은 하이브리드**다. 리그는 자동으로 진행되고, 이용자는 감독으로 지켜보다 원하는 순간 선수로 들어가 직접 치고 던진다.

### 2.1 2013년 모드

| 모드 | 진행 방식 |
|---|---|
| 페넌트레이스 | 10팀 리그에 주 단위로 참가. 6일간 120경기가 매시간 자동으로 열린다. 상위 4팀이 토요일에 포스트시즌. 성적에 따라 상위 리그 승격·잔류·강등. 리그 단계가 오를수록 연봉 총합 상한이 커진다. 주간 시상 있음 |
| 페넌트레이스의 개입 | 작전 지시는 횟수 무제한, **액션 개입은 경기당 3회**. 2차 테스트부터 작전·개입 "예약" 가능 |
| 멀티플레이 — 친선 PvP | 100% 액션으로 대결. 3·6·9이닝 선택. 연봉 상한 없음 |
| 멀티플레이 — 슈퍼심 | 자동 진행을 관전하다 중요한 순간에 작전 지시와 액션 개입 |
| 싱글플레이 | AI 상대. 타격·투구·수비·주루 튜토리얼 포함 |
| 도전과제 | 전 모드에 걸친 과제. 완료 시 게임머니(KP)와 점수 |

### 2.2 경기 시간의 변화

| 시점 | 한 경기 평균 | 조치 |
|---|---|---|
| 1차 테스트 | 약 40분 | "신선하지만 지루하다"는 평가 |
| 2차 테스트 | 15~20분 | 작전·개입 예약, 투구 위치 노출 시간 단축, 원버튼 스킵 |
| 2K14 리뉴얼 | 10~15분 | 플레이타임 재조정 |

### 2.3 2K14 리뉴얼

- **마이플레이어 모드** 추가. 리뉴얼의 중심
- 선수 모델링과 구장 그래픽 개선. 실제 선수 40여 명을 8방향 촬영, 타격·투구 폼 170여 종
- 관중 묘사 강화(응원 도구 등)
- 키보드 전용이던 조작에 **마우스 조작** 추가. 이전 방식도 설정에서 선택 가능
- 주요 메뉴를 화면 하단에 배치하는 UI 개편
- 선택한 **포지션 중심 카메라 시점**

## 3. 조작

### 3.1 2013년 키보드 조작 (인벤 튜토리얼 가이드)

| 상황 | 조작 |
|---|---|
| 컨택트 스윙 | 타이밍에 맞춰 `Space` |
| 파워 스윙 | `F`로 테이크백 후 타이밍에 맞춰 `Space` |
| 번트 | `B`. 투구 전이면 희생 번트, 투구 동작 중이면 기습 번트. `↑` `↓`로 배트 높이 |
| 투구 | 구종 키 선택 → 포수 요구 위치에 자동 지정, 이동 키로 조정 → `Space`를 눌러 게이지를 채운 뒤 뗀다 |
| 견제 | `Shift` + `D`/`W`/`A` = 1루/2루/3루 |
| 송구 | `D` 1루, `W` 2루, `A` 3루, `S` 홈. 송구 게이지는 초록(강하고 정확)·노랑(약하고 부정확)·빨강(강하지만 부정확) |
| 수비 | 방향키로 이동. 왼쪽 `Shift` 중계, `Ctrl` 다이빙, `F` 점프(펜스 캐치) |
| 전체 주루 | 왼쪽 `Shift` 진루, 오른쪽 `Shift` 귀루 |
| 선택 주루 | `Space`로 주자 선택 후 `S`/`D`/`W`/`A` = 홈/1루/2루/3루. 베이스 근처에서 `↑` 슬라이딩 |
| 리드·도루 | 리드 키를 누를 때마다 보폭 증가, 떼면 스타트 |

### 3.2 설정 옵션 (인벤 설정 가이드)

| 옵션 | 내용 |
|---|---|
| 코스 예측 타격 | 스트라이크 존에 원형 커서. 커서 안으로 들어온 공을 치면 비거리 증가 |
| 투구 조작 | 쉬운 투구(`Space`만) / 2K 투구(구종별 방향키 커맨드). 2K 투구가 "맥스" 확률이 더 높다 |
| 포수 리드 | 포수가 구종과 코스를 제시 |
| 수비 이동 | 자동(낙구 지점까지 이동) / 수동 |
| 주루 | 자동(AI가 안전하게) / 수동 |

1차 테스트에서는 간단한 동작에도 어려운 커맨드가 필요했고, 2차 테스트에서 "스페이스바와 방향키만으로" 되는 간편 조작이 기본이 되었다. 세밀한 기존 조작은 옵션으로 남았다.

### 3.3 튜토리얼 구성

타격(컨택트 → 파워 → 번트), 투구(투구 → 견제), 수비(내야 → 외야 → 더블 플레이·다이빙·펜스 캐치), 주루(전체 → 선택 → 도루). 기본 단계를 끝내야 심화가 열린다. 화면 하단에 설명 창, 설명 후 3~5회 연습.

## 4. 구단 운영

### 4.1 로스터

- 로스터는 25명. 타자는 선발 9명 + 후보 5명. 투수는 선발 5명 + 불펜(가이드 표기는 10명인데 합계가 25명과 맞지 않는다)
- 투수 보직은 선발·롱릴리프·미들릴리프·셋업·마무리로 나뉘고 보직별 인원은 이용자가 정한다
- 플래툰 시스템: 상대 선발이 좌완인지 우완인지에 따라 타순을 따로 둔다. 선수 구성은 같고 타순만 다르다
- 연봉 상한: 페넌트레이스는 30에서 시작, 멀티·싱글은 100
- 로스터 자동 추천 기능

### 4.2 선수 수급

| 방식 | 내용 |
|---|---|
| 선수팩 | 상점에서 구매. 9개 구단의 S~C 등급 선수를 무작위 획득 |
| 일일 드래프트 | 하루 한 명을 골라 영입. 목록은 매일 새벽 1시에 갱신 |
| 선수 교환 | 보유 선수 2명 이상을 합쳐 무작위로 새 선수 획득 |

### 4.3 육성

| 시스템 | 내용 |
|---|---|
| 어빌리티 아이템 | 선수당 1개 장착. 합성으로 상위 등급. 타자 8종(컨택터, 슬러거, 리드오프, 스피드스터, 유틸리티, 골드 글러브, 올어라운드, 클러치), 투수 8종(닥터K, 그라운드볼러, 플라이볼러, 컨트롤러, 클로저, 이닝이터, 올어라운드, 위기관리) |
| 특별 훈련 | 이용권 사용. 타자는 타격·주루·수비, 투수는 투구 기술·제구·변화폭 |
| 컨디션 | 선수마다 일정한 주기. 좋으면 능력치 상승, 나쁘면 하락 |
| 팀 효과 아이템 | 싱글플레이 등에서 획득. 같은 선수 구성으로도 팀 색깔이 달라진다 |
| 팀 시너지 | 같은 연도·같은 팀 선수가 로스터에 5/10/15/20/25명일 때 발동. 타자는 컨택트·파워·선구안·주루·수비, 투수는 구위·위기관리·제구·변화폭에 보너스 |

확인된 능력치 이름: 타자 컨택트·파워·선구안·주루·수비, 투수 구위·위기관리·제구·변화폭(구속과 체력도 언급).

개발진은 **부상 시스템을 넣지 않았다.** 이용자 스트레스가 된다는 이유였다.

### 4.4 규모

2013년 기준 특이 폼 263명, 모델링 반영 300명 이상, 모션 6,520여 개(데일리게임). 구장은 실제 구장을 촬영해 제작했고, 구장에서 직접 녹음한 사운드를 썼다.

## 5. 마이플레이어 (2K14)

- 실제 선수를 고르되 **실제 포지션과 무관하게** 원하는 포지션으로 키운다. 포수를 선발 투수로, 거포를 발 빠른 유격수로 키우는 식
- 선수 타입 선택: 컨택터, 슬러거, 스피드스터, 골든글러브, 강속구형, 제구형, 플라이볼러 등
- 경기에서 미션을 수행하면 스킬포인트(SP)를 받고, 타격·수비·주루·구종 등 세부 능력치에 쓴다
- 선구안이 오르면 투구의 코스와 구질이 미리 감지되는 경우가 늘어난다. 장타 기회 타석에는 화면에 표시가 뜬다
- 투수는 구종별로 구속과 제구를 키우고, 조건을 채우면 **구종이 진화**한다(체인지업 → 서클 체인지업). 새 구종 개발도 가능
- 출루하면 주자로 직접 뛴다. 리드가 크면 견제사
- 수비는 선택 포지션 시점에서 직접 한다. 투수는 1루 커버 같은 수비 책임도 진다
- 승부처에는 별도 연출이 붙는다
- 키운 선수를 자신의 팀 엔트리에 넣을 수 있다
- 올스타전: 인기도와 성적으로 뽑힌 22명이 두 팀으로 대결. 홈런레이스: 8명, 3라운드, 홈런 수와 비거리로 보상

## 6. 평가와 교훈

| 관찰 | 우리 설계에 주는 교훈 |
|---|---|
| 경기 시간을 40분 → 10~15분으로 계속 줄였다 | 경기 길이가 가장 큰 변수다. 처음부터 10~15분을 예산으로 잡는다 |
| 어려운 커맨드가 진입 장벽이었다 | 간편 조작이 기본, 고급 조작은 보상이 있는 선택지 |
| 마우스 조작 추가 후 평이 좋아졌다 | 마우스 + 키보드를 기본으로 설계 |
| 선수 등급 책정이 편파적이라는 논란 | 능력치를 공개된 산식으로 기록에서 계산 |
| 팀 시너지가 강해 특정 덱이 고정 메타가 됨 | 팀 보너스에 상한을 두고 조건을 여러 갈래로 |
| 메뉴 동선이 길다(선물 수령에 7번 클릭) | 주요 기능은 3번 이내 클릭 |
| 리뉴얼판은 "장점이 훨씬 많다"는 평. 마이플레이어, 구장, 응원 사운드가 호평 | 커리어 모드와 구장 분위기에 투자 |
| 병살타에 타점이 기록되는 버그 | 기록 규칙을 테스트로 고정 |
| 멀티플레이 중도 이탈 악용 | 1차 범위는 싱글플레이. 해당 없음 |

## 7. 확인하지 못한 것

- **플레이 영상의 내용.** 영상 2건을 찾았지만 페이지에서 제목 외 정보를 읽을 수 없었고, 영상 자체는 볼 수 없다. HUD 배치, 투구 게이지의 생김새, 카메라 구도는 확인하지 못했다. 우리 UI는 새로 디자인하므로 설계에는 영향이 없다
- 디스이즈게임 리뉴얼 인터뷰, 문화일보 리뷰는 접근이 차단되어 읽지 못했다
- 구단별 팀 시너지 수치, 2013년 키 설정 전체 목록은 이미지로만 실려 있어 읽지 못했다
- 능력치 항목 전체 목록, 등급별 연봉 수치, 2K14 마우스 조작의 세부 절차, 마이플레이어의 한 경기 진행 방식과 시즌 길이
- 구단 수 표기가 기사 안에서 9개와 10개로 엇갈린다. 2013년 KBO는 9구단 체제였다
