# 12. 실제 야구 기준 자료

게임에 들어가는 치수·규칙·수치의 근거를 한곳에 모았다. **코드와 데이터 파일의 숫자는 이 문서에서 가져온다.** 여기에 없는 숫자가 필요하면 먼저 이 문서에 근거와 함께 추가한 뒤 구현한다. 구현 순서는 [13 구현 명세](13-implementation-spec.md)에 있다.

## 1. 읽는 법

각 값에는 근거 표시가 붙는다.

| 표시 | 뜻 |
|---|---|
| **K** | KBO 공식 "2026 주요 규정·규칙" 페이지에서 확인 (2026-11-21) |
| **R** | KBO 기록실의 리그 합계에서 확인 (2026-11-21. 720경기, 최근 시즌) |
| **K** | KBO 기록실의 2025 정규시즌 팀 투수 합계에서 확인 (2026-11-21) |
| **W** | 위키백과의 야구장·코치 박스 항목에서 확인 (MLB 공식 규칙 인용) |
| **S** | MLB Statcast 공개 수치에서 확인 |
| **P** | 언론 보도에서 확인. 검색 결과의 요약으로 확인했고 기사 원문은 열어 보지 않았다 |
| **O** | 공식 야구 규칙의 값으로 알고 있으나 이번에 원문을 다시 확인하지 못함. 서로 맞물리는 다른 값과는 일치한다 |
| **A** | 가정. 실측 근거가 없어 시뮬레이션 분포를 보며 조정할 값 |
| ✔ | 이미 코드에 들어가 있고 테스트가 값을 고정한다 |

**O**와 **A**는 [10절](#10-확인이-필요한-항목)에 모아 두었다. 해당 기능을 구현하기 직전에 원문을 확인하고 표시를 바꾼다.

단위는 미터·초·킬로그램이다. 규칙서의 값은 피트·인치이므로 둘을 함께 적는다. 좌표는 [04](04-physics.md#2-좌표계와-단위)의 필드 좌표(+x 1루 쪽, +y 홈에서 중견수 쪽, +z 위, 원점은 홈 플레이트 꼭짓점)다.

### 5.3 기록 규칙에서 틀리기 쉬운 것

구현할 때 테스트로 고정한다([13](13-implementation-spec.md#s4-규칙과-통계-해석기)).

- 병살타에는 타점이 없다. 실책으로 들어온 점수에도 없다(실책이 없었어도 들어왔을 점수는 예외)
- 세 번째 아웃이 포스 아웃이거나 타자 주자가 1루에 닿기 전의 아웃이면, 그 플레이에서 먼저 홈을 밟은 주자의 득점은 인정되지 않는다. 태그 아웃이면 아웃보다 먼저 들어온 점수는 인정된다
- 자책점은 실책과 포일이 없었다고 가정하고 이닝을 다시 구성해서 센다. 투수가 바뀌면 남겨 둔 주자는 앞 투수의 책임이다
- 선발 투수는 5이닝 이상 던져야 승리 투수가 된다. 못 채우면 기록원이 가장 효과적이었던 구원 투수에게 준다(게임에서는 리드를 잡은 뒤 가장 많은 아웃을 잡은 구원 투수)
- 세이브: 이긴 경기를 끝낸 투수이고 승리 투수가 아니며, (3점 이하 리드에서 1이닝 이상) 또는 (동점 주자가 루상·타석·대기 타석에 있을 때 등판) 또는 (3이닝 이상 투구)
- 홀드: 세이브 상황에 등판해 아웃을 하나 이상 잡고 리드를 지킨 채 내려간 중간 투수
- 낫아웃은 1루가 비었거나 2아웃일 때만 성립한다. 삼진 기록은 그대로 남는다
- 인필드 플라이는 무사 또는 1사, 주자 1·2루 또는 만루, 내야수가 평범하게 잡을 수 있는 페어 뜬공(번트와 직선타 제외)
- 희생 플라이는 타수에 넣지 않고 출루율 분모에는 넣는다. 희생 번트는 둘 다에 넣지 않는다
- 지명타자가 수비로 들어가거나, 투수가 다른 수비 위치로 가거나, 대타가 투수로 남으면 그 팀의 지명타자는 사라진다

## 7. 선수 운동 수치

MLB의 공개 측정값이다. KBO 측정값은 공개된 것이 적어 MLB 평균을 능력치 60 부근, KBO 평균을 50으로 둔다(**A**. S5의 분포 검사에서 조정).

| 항목 | 평균 | 범위 | 근거 | 게임의 식([04](04-physics.md#10-선수-운동-모델)) |
|---|---|---|---|---|
| 최고 주루 속도 | 27 ft/s (8.23 m/s) | 23~30.5 ft/s (7.0~9.3). 중견수 평균 28.2, 포수·지명타자 26 미만 | S | `lerp(7.0, 9.3, 주력/99)` m/s, 가속 v(t) = v_max(1 − e^(−t/0.6)) |
| 타석~1루 | 우타 약 4.3초, 좌타 약 4.2초 | 3.9~4.8초 | A (스카우트 기준 평균) | 스윙 뒤 출발 0.40초(좌타 0.42) + 가속 모델. 주력 50 우타 4.30초, 좌타 4.18초 |
| 포수 팝 타임(2루) | 2.0초 | 1.85~2.15초 | S | 공 빼기 `lerp(0.85, 0.55, 포구)` + 송구. 송구력·포구 50에서 2.01초 |
| 포수 공 빼는 시간 | 약 0.7초 | 0.6~0.8초 | S | 팝 타임에 포함 |
| 송구 속도(최대 노력 평균) | 1루수 78.4, 2루수 79.3, 3루수 85.6, 유격수 85.7, 좌익수 87.1, 중견수 89.6, 우익수 90.5 mph | 포지션 안에서 ±8 mph | S (2025년 리그 평균. 열 순서는 추정) | 내야 `lerp(112, 146)`, 외야 `lerp(120, 156)` km/h. 평균이 126~146km/h로 일치한다 |
| 투수 퀵 모션(동작 시작~포수 미트) | 약 1.3초 | 1.2~1.5초 | A (스카우트 기준) | 1.20~1.50초 |
| 1루 리드 | 3.0~3.7m | 최대 4.2m | A | 3.0~4.2m |
| 야수 반응 | 땅볼 약 0.2초, 뜬 공 약 0.45초 | | A (S5 보정) | 땅볼 `lerp(0.32, 0.12)`, 뜬 공(외야수, 그리고 라인드라이브·팝업을 받는 내야수) `lerp(0.70, 0.32)`. 능력치 60에서 각각 0.20초, 0.47초 |
| 병살 피벗 | 약 0.5초 | | A (S5 보정) | `lerp(0.65, 0.35, 포구)`. 18m 미만의 토스는 송구 동작의 60% 시간 |
| 주자 출발 | | | A (S5 보정) | 타구를 읽는 `lerp(0.30, 0.12, 주루)`초에서 2차 리드의 움직임 0.15초를 뺀다. 2아웃이면 0.25초 앞서 출발 |

도루를 예로 들면, 배터리 시간은 퀵 모션 1.3초 + 팝 타임 2.0초 = 3.3초이고, 리그 도루 성공률이 74.5%(8.2절)가 되도록 주자의 스타트와 가속을 맞춘다.

## 9. 구종

구종 카탈로그는 [04](04-physics.md#53-구종-카탈로그-우완-초기값)에 있다(8종. 구속·회전수·회전 효율·기울기). KBO의 구종별 평균 구속과 구사율은 이번에 확인하지 못했다(2025년부터 전 구장이 같은 측정 장비를 쓴다는 것만 확인. P). 선수별 구속은 S17에서 문자중계 기록으로 모은다. 가상 리그의 구속 분포는 직구 평균 144km/h, 표준편차 3.5km/h로 둔다(A).

**심 시프트 웨이크(2026-11-21, 승인된 제안 1)**: 투심·체인지업·스플리터에는 회전(매그너스)으로 설명되지 않는 추가 움직임이 있다(Smith & Smith 2021, Proc. IMechE Part P 235(1); Smith·Nathan·Pavlidis 2020). 카탈로그에 실밥 추진(`ssw_accel` m/s², `ssw_deg` 방향)을 두었다: 투심 0.9(−115°, 팔 쪽 아래), 체인지업 1.0(−110°), 스플리터 0.8(−160°). 총 무브먼트(투심 −34.3/28.5cm, 체인지업 −35.9/20.5cm, 스플리터 −8.4/13.2cm)는 그대로 두고 회전 효율·기울기를 다시 맞췄다(투심 0.794/−39.9°, 체인지업 0.699/−46.7°, 스플리터 0.49/−17.7°, 기준 계산 `prototypes/physics-check/check.mjs`). 투수마다 구종 무브먼트 능력치와 개인차로 0.5~1.5배(`PhysicalResolver.ssw_scale_for`) — 같은 회전수라도 투수마다 휘는 정도가 다르다.
