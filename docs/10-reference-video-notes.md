# 10. 참고 영상 분석

`reference/`에 있는 플레이 영상 2개에서 읽어 낸 내용과, 그것을 설계에 어떻게 반영했는지의 기록. 분석일 2026-11-20.

영상에서 가져오는 것은 **무엇이 화면에 있고, 언제 나오고, 얼마나 걸리는가**다. 화면의 생김새(색, 모양, 로고, 글꼴)는 가져오지 않고 새로 디자인한다.

## 1. 분석 방법과 한계

| 항목 | 내용 |
|---|---|
| 영상 A | `reference/ref-a.mp4`. 9분 13초, 576×360. 마이플레이어 한 경기 전체(로비 → 능력치 배분 → 경기 → 보상) |
| 영상 B | `reference/ref-b.mp4`. 35분 53초, 640×360. 대전·올스타전·관전 장면 모음. 홍보 영상과 서비스 종료 공지 화면 포함 |
| 방법 | 10~30초 간격의 전체 훑어보기, 주요 장면은 0.4초 간격 연속 프레임, HUD는 2배 확대 정지 화면. 소리는 스펙트로그램으로 구조만 확인 |
| 한계 | 360p라 작은 글자는 읽지 못했다. 능력치 행의 이름, 키 힌트의 일부, 숫자 배지의 의미는 추정이다. 소리는 들을 수 없어 "음악인지 관중인지" 정도만 구분했다. 영상 B는 녹화 프로그램 표시가 있고 편집본이라 음성은 분석하지 않았다 |

## 2. 마이플레이어 한 경기의 흐름 (영상 A)

| 시각 | 화면 | 내용 |
|---|---|---|
| 0:00 | 로비 | 구장을 배경으로 한 3D 화면. 하단에 아이콘 메뉴 7개(홈, 마이플레이어, 대전, 리그, 구단 관리, 상점·인벤토리 등), 우하단 채팅창 |
| 0:10 | 구단 관리 | 선수 목록 표. 등급, 포지션, 능력치 여러 열 |
| 0:20 | 인벤토리 | 성장 포인트 부스트 아이템("100%, n경기") 사용 |
| 0:50 | 능력치 배분 | 왼쪽에 선수 상반신 3D, 오른쪽에 능력치 행(현재 값, −/+ 조절, 다음 단계 비용, 목표 값). **타격·수비·주루 포인트가 따로 쌓인다**(4,284 / 255 / 175) |
| 1:30 | 경기 시작 연출 | 팀 로고가 나오는 전환 화면 |
| 1:40 | 상황판 | 이닝별 점수표, 양 팀 타순과 능력치, 가운데 다이아몬드(이닝·아웃), 현재 투수·타자 카드, 캐스터·해설 얼굴 패널 |
| 1:50 | 타격 장면 | 내 타석. 아래 3절 |
| 사이사이 | 상황판 | 내가 관여하지 않는 타석은 **결과가 한 줄씩 쌓이는 목록**으로 지나간다. 수비 기회가 오면 "Space: 수비" 안내 |
| | 장면 카드 | 장면 진입 전에 작은 카드: 미니 점수표 + **이번 장면의 목표**("유리한 볼카운트 만들기", 투수는 "타자를 삼진 아웃 시키기") + 플레이 버튼 |
| | 주루 장면 | 내 선수 뒤 3인칭. 발밑에 파란 고리와 이름, 베이스 위에 번호 표식, 진행 방향 화살표, 좌상단 미니 다이아몬드와 마우스 버튼 안내 |
| | 수비 장면 | 내 포지션 뒤 3인칭. 타구가 오면 처리하고 송구 |
| | 승부처 | 화면 상단 양쪽에 불꽃 고리 효과, 선수 클로즈업 |
| 7:55 | 경기 종료 | 경기 MVP 연출(팀 로고 + 선수 얼굴 + 이름) |
| 8:20 | 보상 | 성적에 따른 메달 등급 상자 → 돌림판 추첨 |
| 8:30 | 능력치 배분 | 얻은 포인트로 성장 |
| 9:00 | 순위표 | 마이플레이어 타자 순위 |

**소요 시간**: 야수 한 경기 약 6분 20초. [02](02-game-design.md#62-한-경기의-흐름)의 예상(6~8분)과 맞는다.

## 3. 경기 화면의 구성 요소

### 3.1 타격 화면

| 요소 | 관찰 |
|---|---|
| 카메라 | **타자 뒤 3인칭.** 타자가 화면 왼쪽 3분의 1을 크게 차지하고, 홈플레이트가 아래 가운데, 투수는 가운데에 작게 보인다. 뒤로 외야 전광판과 관중석, 하늘이 넓게 들어온다 |
| 점수 표시 | 상단 가운데. 볼카운트 점과 주자 표시가 있는 작은 다이아몬드, 양 팀 로고·이름·점수, 가운데 이닝 |
| 스트라이크 존 | 포수 앞에 옅은 사각형. 코스 예측용 원형 커서 |
| 구속·구종 | 공이 도착한 지점에 원형 표시("133 KM/H")와 구종 이름 |
| 투구 기록 패널 | 오른쪽. 3×3 존에 이번 타석의 투구 위치가 점으로 찍힌다. 같은 자리에 **투수의 코스 분포**(칸마다 횟수)가 번갈아 나온다 |
| 화면 속 화면 | 우상단 작은 창에 투수(또는 주자) 쪽 다른 각도. 숫자 배지가 붙는다(의미 미확인) |
| 하단 바 | 왼쪽 타자, 오른쪽 투수. 연도·이름, 종합 수치, 포지션·보직. 양끝에 TAB 표시 |
| TAB 상세 | 누르면 하단에 카드 2장이 펼쳐진다. 타자: 능력치, 시즌 기록, 오늘 기록. 투수: 상태 막대 2개, 시즌 기록, 오늘 기록 |
| 타격 순간 | 존 사각형이 노랗게 빛나고 공에 광채 |
| 전광판 | 외야 전광판에 현재 타자 사진이 실제로 나온다 |

### 3.2 투구 화면

| 요소 | 관찰 |
|---|---|
| 카메라 | **투수 뒤 낮은 3인칭.** 투수의 등번호와 이름이 보이고, 가운데에 타자·포수·심판. 배경은 백스톱 뒤 광고판과 **가까운 관중석** |
| 투구 게이지 | 목표 지점을 둘러싼 **고리 모양**. 구종 이름이 고리 위에 붙는다. 고리가 줄어들거나 돌면서 타이밍을 잰다. 결과 판정 글자("GOOD")가 고리 안에 나온다 |
| 코스 표시 | 목표 지점 위에 화살표 표식 |
| 하단 바 | 기능 키 안내 3개(선수 교체, 투구 정보, 수비 위치로 추정) |
| 그 밖 | 타격 화면과 같은 점수 표시, 투구 기록 패널, 구속 표시 |

**투구 한 개의 흐름** (0.4초 간격 측정)

| 구간 | 길이 |
|---|---|
| 장면 카드(목표) 표시 | 플레이어가 넘길 때까지 |
| 구장 전경 샷 | 약 1초 |
| 구종·코스 지정에서 투구 동작 시작까지 | 약 3초 |
| 투구 동작 시작에서 릴리스까지 | 약 2초 |

### 3.3 수비·주루 화면

| 요소 | 관찰 |
|---|---|
| 카메라 | 내야 뒤 높은 위치에서 공을 따라간다. 외야 타구는 더 넓게 |
| 미니 다이아몬드 | 좌상단. 주자 위치에 번호 배지, 가운데에 중계 키 안내 |
| 베이스 표식 | 경기장 안 베이스 위에 노란 마름모와 번호(홈은 H) |
| 송구 게이지 | **송구 대상 베이스 표식 옆에** 가로 막대. 녹색 구간이 있다 |
| 선택된 야수 | 발밑 파란 고리와 이름 |
| 자동 이동 표시 | 야수 근처에 글자 |
| 방향 표시 | 화면 가장자리가 노랗게 빛난다(화면 밖의 공이나 주자 방향으로 추정) |
| 거리 표시 | 펜스에 거리 숫자 |

### 3.4 상황판

감독·마이플레이어의 "지켜보는" 화면이다. 3D 경기장을 어둡게 깔고 그 위에 표를 올린다.

| 영역 | 내용 |
|---|---|
| 상단 | 이닝별 점수표 (1~12회, R·H·E·B) |
| 좌우 | 양 팀 타순 9명 + 투수. 포지션, 종합 수치, 능력치 열. 현재 타자 강조 |
| 가운데 | 다이아몬드(이닝, 초·말, 아웃), 그 아래로 타석 결과 목록 |
| 하단 | 현재 타자와 투수 카드(사진, 기록, 상태 막대) |
| 안내 | 개입 가능할 때 키 안내. 관전 모드에서는 우하단에 작전 메뉴·예약 키 안내 |

## 4. 연출

| 시점 | 관찰 |
|---|---|
| 경기 전 | 팀 로고 전환 화면 → 선발 투수 카드(승패, 평균자책점, 삼진)와 주목할 타자 → 타순 목록 오버레이(선수 사진, 수치, 타율·홈런·타점) → 캐스터·해설 패널 |
| 타석 진입 | 타자 클로즈업 후 타격 화면 |
| 투구 전 | 구장 전경 샷 1초 |
| 승부처 | 상단 효과 + 클로즈업 |
| 타구 후 | 타격 화면에서 수비 화면으로 전환 |
| 판정 | 화면 가운데 글자("세이프") |
| 이닝 교대 | 상황판 또는 짧은 전환 |
| 경기 후 | 경기 MVP, 보상 추첨 |

## 5. 구장과 관중

| 요소 | 관찰 | 설계에 주는 의미 |
|---|---|---|
| 가까운 관중 | 백스톱 뒤 관중은 한 명 한 명이 3D 인물이다. 옷 색이 다양하고 일부는 서 있으며 응원 막대를 든다 | 투구 화면에서 화면의 3분의 1이 이 관중이다. **가장 자주, 가장 크게 보이는 배경**이므로 가까운 구역의 품질이 중요하다 |
| 먼 관중 | 외야·상단 관중석은 촘촘한 색 점 | 밀도가 중요 |
| 광고판 | 백스톱, 외야 펜스, 관중석 전면에 띠 모양 광고판 | 구장의 인상을 크게 좌우한다 |
| 전광판 | 타자 사진과 기록이 나온다 | 실제로 동작하는 전광판 |
| 원경 | 구장 밖으로 산, 아파트, 고층 건물 | 구장마다 다른 배경 |
| 하늘 | 구름, 비행선 | 타격 화면의 절반이 하늘이다 |
| 시간대 | 낮과 밤. 밤에는 조명탑이 켜진다 | |
| 구장 수 | 실제 구장 여러 곳이 번갈아 나온다 | |

## 6. 소리 (영상 A 스펙트로그램)

| 구간 | 관찰 | 해석 |
|---|---|---|
| 메뉴 (0:00~1:10) | 끊기지 않는 화성 성분과 일정한 저음 | 배경 음악이 계속 나온다 |
| 로딩 | 무음 | |
| 경기 시작 직전 | 짧은 화성 성분 | 시작 음악 |
| 경기 중 | 넓은 대역의 잡음이 바탕. 그 위에 화성 성분 덩어리가 주기적으로 얹힌다 | **상시 배경 음악은 없다.** 관중 소리가 바탕이고 응원(악기·구호)이 주기적으로 나온다 |
| 상황판 전환 | 음량이 줄어든다 | 경기장 소리를 낮춘다 |
| 경기 후 | 조용한 화성 성분 | 결과 화면 음악 |

음성 해설이 나오는지는 스펙트로그램으로 가려낼 수 없었다. 기사에 따르면 캐스터와 해설위원의 녹음이 있었다.

## 7. 설계에 반영한 것

| 관찰 | 반영 | 문서 |
|---|---|---|
| 장면마다 목표 카드 | 커리어의 목표를 "경기당 3개"에서 "장면마다 1개 + 경기 목표 1개"로 변경 | [02](02-game-design.md#63-성장) |
| 성장 포인트가 분야별로 분리 | 타격·수비·주루·투구 포인트를 따로 쌓는다. 그 분야의 플레이로만 얻는다 | 〃 |
| 경기 후 메달 등급과 추첨 | 경기 평점 → 메달 등급 → 보상 상자 | 〃 |
| 건너뛰는 구간을 결과 목록으로 | 상황판 화면 추가. 감독 지휘와 커리어가 함께 쓴다 | [05](05-controls-camera-ui.md#35-상황판) |
| 타자 뒤 3인칭, 투수 뒤 낮은 3인칭 | 두 카메라를 기본값으로 변경 | [05](05-controls-camera-ui.md#4-카메라) |
| 투구 기록 패널, 화면 속 화면, 구속 표시, TAB 상세, 키 안내 줄, 가장자리 방향 표시 | HUD 요소 목록에 추가 | [05](05-controls-camera-ui.md#3-화면-구성-hud) |
| 송구 게이지가 대상 베이스 옆에 | 야수 머리 위에서 베이스 표식 옆으로 변경 | 〃 |
| 고리 모양 투구 게이지 | 게이지를 목표 지점에 겹쳐 그린다(시선이 한곳에 머문다). 모양은 새로 디자인 | [05](05-controls-camera-ui.md#21-투구) |
| 투구 전 전경 샷, 경기 전·후 연출 | 연출 목록에 추가 | [11](11-audio-and-atmosphere.md#6-중계-연출) |
| 가까운 관중이 개별 3D 인물 | 관중을 3단계로. 가까운 구역은 인물 메시 | [06](06-3d-art-pipeline.md#7-관중) |
| 원경, 하늘, 광고판, 동작하는 전광판 | 구장 생성기의 필수 요소로 | [06](06-3d-art-pipeline.md#6-구장) |
| 경기 중 상시 음악 없음, 관중 소리가 바탕 | 소리 설계의 기본 구조로 | [11](11-audio-and-atmosphere.md) |

## 8. 최종 점검표

마지막 단계([08](08-roadmap.md)의 S19)에서 아래 요소가 모두 있는지 영상과 나란히 놓고 확인한다. 기준은 "같은 정보가, 같은 시점에, 비슷한 밀도로 화면에 있는가"다. 모양이 같은지는 기준이 아니다.

| 화면 | 있어야 하는 것 |
|---|---|
| 허브 | 3D 구장 배경, 주요 메뉴 한 줄, 내 구단·선수 요약 |
| 능력치 배분 | 선수 3D 표시, 능력치 행, 조절, 비용, 분야별 포인트 |
| 구단 관리 | 선수 표, 정렬·필터, 로스터 편성, 코스트 표시 |
