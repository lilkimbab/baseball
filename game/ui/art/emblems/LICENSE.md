# Emblem mascots

The mascot drawings in this folder are from game-icons.net (https://game-icons.net,
https://github.com/game-icons/icons), licensed under Creative Commons Attribution 3.0
(https://creativecommons.org/licenses/by/3.0/). Authors: Lorc (lorc), Delapouite (delapouite),
Caro Asercion (caro-asercion), Cathelineau (cathelineau), and the set's badges. Changed: the
black square behind each drawing was removed so the drawing stands on the club's colours.
`index.json` says which club nickname takes which drawing (`Emblem` in `game/ui/kit/emblem.gd`).
