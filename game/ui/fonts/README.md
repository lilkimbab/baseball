# Fonts in the game

Every face here may be redistributed (SIL Open Font License 1.1 unless noted); the licence
texts are beside the files or at the addresses below. Which face is used where is decided in
`game/ui/ui_theme.gd` (`UiTheme.face`), and for the uniforms in `game/match/uniform_fonts.gd`.

| Face | Files | Used for | Source | Licence |
|---|---|---|---|---|
| Paperlogy | `Paperlogy-*.woff2` | menus: all Korean text and headings | noonnu.cc (Lee Ju-im, Kim Do-gyun) | OFL 1.1 (`Paperlogy-LICENSE.txt`) |
| Barlow Condensed | `BarlowCondensed-*.ttf` | figures and Latin labels everywhere (scores, ratings, speeds) | github.com/google/fonts | OFL 1.1 (`BarlowCondensed-OFL.txt`) |
| S-Core Dream | `SCoreDream-*.woff` | the broadcast graphics over a game (score bug, bottom bar, pitch panel, commentary line) | S-Core, via noonnu.cc | OFL 1.1 (s-core.co.kr) |
| Gmarket Sans | `GmarketSans-*.woff` | sponsors' boards (one of their brand faces) | Gmarket, via noonnu.cc | OFL 1.1 (corp.gmarket.com/fonts) |
| Galmuri 11 | `Galmuri11-Bold.ttf` | the stadium scoreboard (a dot-matrix face) | github.com/quiple/galmuri | OFL 1.1 |
| Black Han Sans | `../../assets/fonts/uniform/BlackHanSans-Regular.ttf` | umpires' calls and judgments on screen; names on uniforms; sponsors' boards | github.com/google/fonts | OFL 1.1 |
| Do Hyeon | `../../assets/fonts/uniform/DoHyeon-Regular.ttf` | names on some clubs' uniforms; sponsors' boards | github.com/google/fonts | OFL 1.1 |
| College Block | `../../assets/fonts/uniform/CollegeBlock-*.ttf` | uniform numbers and letters (fallback), distances on the outfield wall | Matthew Welch, squaregear.net | MIT-style (`CollegeBlock-LICENSE.txt`) |
| Lobster, Rye | `../../assets/fonts/uniform/` | script and Tuscan lettering on uniforms (fallbacks), sponsors' boards | github.com/google/fonts | OFL 1.1 |
