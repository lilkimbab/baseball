# Fonts in the game

Every face here may be redistributed unmodified (SIL Open Font License 1.1 unless noted); the licence
texts are beside the files or at the addresses below. Which face is used where is decided in
`game/ui/ui_theme.gd` (`UiTheme.face`), and for the uniforms in `game/match/uniform_fonts.gd`.

| Face | Files | Used for | Source | Licence |
|---|---|---|---|---|
| NEXON Lv.2 Gothic | `nexon_lv2/NEXONLv2Gothic-*.woff` | menus: all Korean text (the default family since 2026-11-23) | Nexon Korea, via noonnu.cc | Nexon font policy: free, bundling allowed unmodified with the notice (`nexon_lv2/LICENSE-NEXON.txt`) |
| Giants | `giants/Giants-*.woff2` | the broadcast graphics over a game (score bug, bottom bar, pitch panel, commentary line) and menu headings (Bold); shouted calls (Inline) | Lotte Giants (made by T-Lab), via noonnu.cc / Sandoll Cloud | free, bundling allowed unmodified with the notice; the font itself may not be sold (`giants/LICENSE-Giants.txt`) |
| Paperlogy | `Paperlogy-*.woff2` | menus, when chosen in the settings | noonnu.cc (Lee Ju-im, Kim Do-gyun) | OFL 1.1 (`Paperlogy-LICENSE.txt`) |
| Barlow Condensed | `BarlowCondensed-*.ttf` | figures and Latin labels everywhere (scores, ratings, speeds) | github.com/google/fonts | OFL 1.1 (`BarlowCondensed-OFL.txt`) |
| S-Core Dream | `SCoreDream-*.woff` | menus, when chosen in the settings | S-Core, via noonnu.cc | OFL 1.1 (s-core.co.kr) |
| Gmarket Sans | `GmarketSans-*.woff` | sponsors' boards (one of their brand faces) | Gmarket, via noonnu.cc | OFL 1.1 (corp.gmarket.com/fonts) |
| Galmuri 11 | `Galmuri11-Bold.ttf` | the stadium scoreboard (a dot-matrix face) | github.com/quiple/galmuri | OFL 1.1 |
| Black Han Sans | `../../assets/fonts/uniform/BlackHanSans-Regular.ttf` | names on uniforms; sponsors' boards | github.com/google/fonts | OFL 1.1 |

| Anton, Sancreek, Damion | `../../assets/fonts/uniform/` | block, Tuscan and script lettering on uniforms when the local pack's faces are not there (the public build) | github.com/google/fonts | OFL 1.1 |
| College Block | `../../assets/fonts/uniform/CollegeBlock-*.ttf` | distances on the outfield wall | Matthew Welch, squaregear.net | MIT-style (`CollegeBlock-LICENSE.txt`) |
